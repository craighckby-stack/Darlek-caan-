## 💡 What Is DARLEK CAAN?

**DARLEK CAAN** is an enterprise-grade, interactive AI-powered code analysis, repository management, and autonomous evolution platform. Siphoning advanced architectural patterns from world-class systems like `AI_Agent_OS` and Microsoft's agentic frameworks, DARLEK CAAN provides a secure, sandboxed environment to inspect, refactor, optimize, and self-heal codebases autonomously.

At its core, the platform orchestrates a **Multi-LLM Debate Chamber** where diverse models (Gemini, OpenAI, DeepSeek, Anthropic, and local runtimes) negotiate code mutations, weighing risk scores, performance metrics, and security implications before committing changes directly to GitHub.

## ✨ Key Features

- **🤖 Automated Code Evolution**: Select files from your GitHub repository to let AI propose refactors, performance optimizations, and code cleanups.
- **🏛️ Multi-LLM Debate Chamber**: Multiple AI models debate code improvements before applying them, weighing risks, pros, and cons to ensure high-quality, bug-free changes.

## ⚙️ Core Subsystems

### 1. Diagnostic Engine & Telemetry
Siphoned from the high-performance `AI_Agent_OS` kernel, our diagnostic suite performs deep integrity checks on startup and during active evolution cycles:
- **Kernel Integrity**: Validates environment variables, memory persistence layers, and module registry status.
- **Telemetry Generation**: Measures execution duration in milliseconds, tracks thread IDs, and generates ISO 8601 UTC timestamps.
- **Gatekeeper Policy**: Automatically blocks unsafe mutations if system health falls below the critical threshold.

### 2. Zero-Dependency Environment Validator
To guarantee runtime safety and prevent configuration drift, the system utilizes a custom TypeScript validator (`src/config/env.ts`) that:
- Parses and validates all critical API keys (OpenAI, Gemini, Anthropic, DeepSeek).
- Enforces strict typing on system parameters (e.g., `DEBATE_CONSENSUS_THRESHOLD`, `MAX_MUTATION_DEPTH`).
- Provides clear, actionable error messages on missing or malformed variables without relying on heavy external dependencies.

### 3. Zero-Leak Sandboxing
Protects sensitive data and prevents file-watcher exhaustion during autonomous agent self-refactoring cycles through:
- Advanced `.gitignore` rules covering modern runtimes (Bun, Deno), monorepo build systems (Turborepo, Nx), and Python virtual environments.
- PII sanitization pipelines siphoned from `Git-Secret-PII-Sanitizer` to ensure API keys and credentials never leak into commits.

## 📖 How To Use

### 1. Connect Your GitHub Account
1. Open the [Live Application](https://ais-pre-amubz4v3czr3772fnvrcru-483535245139.asia-southeast1.run.app).
2. Enter your **GitHub Personal Access Token** in the setup panel to grant permissions to inspect or update your repositories.
3. Select an active repository and branch from your account.

### 2. Propose & Evolve Code
1. Select a file from the repository tree view.
2. Click **"Evolve Code"** or **"Propose Mutation"**.
3. Watch as AI models analyze the file and present proposed changes along with a side-by-side diff.
4. Review the AI Debate output to see the pros, cons, and safety score of the proposed changes.
5. Click **Approve & Commit** to automatically push changes directly to your GitHub repository, or **Reject** to discard them.

### 3. Compile a New Repository From a Specification
1. In the main prompt input, describe your application or upload a specification document.
2. Enter a name for your new repository.
3. Click **Compile & Build** to let DARLEK CAAN generate the codebase and push it to your GitHub account.

### 4. Enable Batch Evolution Mode
1. Toggle **Batch Mode** to allow the system to sequentially analyze and propose improvements across multiple files in your repository.
2. Set your preferred **Auto-Approve Risk Threshold** (Low, Medium, or Manual Check) to control how much autonomy the AI has.
